# Copilot Instructions

- Use Python 3.12 and Flask best practices.
- Keep code modular and reusable.
- Use descriptive variable and function names.
- Follow PEP 8.
- Add type hints where appropriate.
- Separate game logic from Flask routes.
- Use vanilla JavaScript for frontend interactions.
- Write responsive CSS for desktop and mobile.
- Add comments only where necessary.
- Use pytest for testing.
- Explain any complex code before generating it.
